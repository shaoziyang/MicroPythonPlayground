关于 MicroPython Playground

    

    

      

        
        
一个基于 WebAssembly 的本地 MicroPython 交互式运行环境。代码全部在浏览器内编译执行，无需连接服务器。

      

      

        当前内核版本：检测中…
        PHP 版本：检测中…
      

      

        程序版本：v1.1.31

          Gitee
        
        

      

      
主要功能

      
    
        
  • 编辑器 Python 语法高亮，亮 / 暗主题切换
    • 
        
  • REPL 交互输入、表达式回显与 Tab 补全
    • 
        
  • 两级示例菜单（按类别浏览）与常用链接
    • 
        
  • 检查并更新内核，支持多 CDN 与 PHP 本地更新
    • 
        
  • 上下 / 左右分区切换，拖动分割条调整
    • 
        
  • 代码、主题与布局自动保存到本地（file 模式用 localStorage，HTTP 模式兼容 Cookie）
    • 
      

      
快捷键

      
    
        
  • Ctrl / ⌘ + Enter 运行代码
    • 
        
  • Tab 补全 / 缩进
    • 
        
  • Ctrl / ⌘ + J 切换主题
    • 
        
  • 双击分割条重置分区比例
