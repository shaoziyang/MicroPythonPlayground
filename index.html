选项

    

      

        

          
外观主题

          
切换亮色 / 暗色界面，快捷键 T 或 Ctrl/⌘ + J（全局有效）

        

        
      

      

        

          
标签页样式

          
切换顶部标签的外观，选中后立即生效并自动保存，刷新后保留。

        

        

          
        

      

      

        

          
编辑区 / 输出区布局

          
切换上下 / 左右分区，快捷键 L（仅在 mpy 标签页有效）

        

        
      

      

        

          
保留 REPL 历史命令数量

          
输入 ↑/↓ 可回溯的命令条数，刷新或重新载入后不丢失。范围 0–500，填 0 表示不保留。

        

        
        
      

    

    

      

        

          
数据导出

数据导入

          
从之前导出的 JSON 文件恢复全部参数与 /flash 文件；导入会覆盖现有数据并自动重新加载页面。

py

      
MicroPython 工具箱

      power by WorkBuddy
    

    

      

        
        
一个基于 WebAssembly 的本地 MicroPython 交互式运行环境。代码全部在浏览器内编译执行，无需连接服务器。

主要功能

        
    
          
  • 编辑器 Python 语法高亮，亮 / 暗主题与四种标签样式切换
    • 
          
  • REPL 交互、表达式回显、Tab 补全与命令历史持久化
    • 
          
  • 多文件编辑器 + /flash 文件列表，新建 / 改名 / 删除 / 右键菜单
    • 
          
  • 本地 ./lib 映射为 /lib，可 import 外部模块
    • 
          
  • 两级示例菜单（统一在 demo.py 打开）与常用链接
    • 
          
  • /flash 持久化到 localStorage，刷新自动运行 main.py
    • 
          
  • 一键导入 / 导出全部本地数据，检查并更新内核（多 CDN / PHP）
    • 
          
  • 上下 / 左右分区、拖拽分隔条调整，代码与布局自动保存
